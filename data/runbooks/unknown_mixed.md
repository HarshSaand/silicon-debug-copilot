# Unknown or mixed evidence

Runbook ID: `RB-UNKNOWN`

Use when evidence is contradictory, incomplete, or spans multiple subsystems
without a supported primary cause.

1. Summarize only directly observed symptoms.
2. Cite every material statement to a log line.
3. State which information is missing.
4. Recommend bounded data collection rather than a speculative repair.
5. Abstain from root-cause claims.
