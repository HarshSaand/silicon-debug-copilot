# Memory and ECC triage

Runbook ID: `RB-ECC`

Use when corrected or uncorrected memory errors are explicitly recorded.

1. Distinguish corrected from uncorrected errors.
2. Aggregate events by location only when a stable location is present.
3. Check recurrence and proximity to resets or thermal events.
4. Preserve syndrome/location fields without inventing missing values.
5. Escalate uncorrected errors; monitor isolated corrected events according to
   platform policy.
